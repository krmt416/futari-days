# Futari Days — ふたりのカウントダウン＆タスク帳

婚約日・両家顔合わせ・結婚式まで「あと何日」を表示し、その日に必要なタスクをふたりで管理する PWA。
**GitHub Pages（画面）＋ Google Apps Script（API）＋ スプレッドシート（DB）** だけで動きます。Google Cloud は不要です。

```
スマホ/PC ──(GitHub Pages: docs/)──▶ GAS ウェブアプリ ──▶ スプレッドシート
      └─ 合言葉でログイン ─▶ GASが照合 ─▶ 正しければ30日のセッションを発行
```

## セットアップ（約10分）

### 1. スプレッドシート＋GAS
1. 新しいスプレッドシートを作る（**共有はしない**）
2. 拡張機能 → Apps Script → `gas/Code.gs` の中身を貼り付け
3. 歯車（プロジェクトの設定）→「"appsscript.json" マニフェスト ファイルをエディタで表示」をON → `gas/appsscript.json` の中身で置き換え

### 2. 合言葉を決める（コードには書かない）
プロジェクトの設定 → スクリプト プロパティ → 追加

| プロパティ | 値 |
|---|---|
| `PASSPHRASE` | ふたりだけの合言葉（**10文字以上**。日本語・スペース可。例：2人の思い出の一文） |

エディタで `selfCheck` を実行 → 権限を承認 → ログに「OK」が出ればOK。

### 3. ウェブアプリとして公開
デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**全員**（認証は合言葉で行います）

表示された `…/exec` の URL を控える。

### 4. GitHub Pages
1. `docs/config.js` の `GAS_URL` に手順3のURLを入れる
2. このフォルダを GitHub に push
3. Settings → Pages → Branch: `main` / Folder: `/docs`
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` を2人のスマホで開く
5. 合言葉を入力 →「どっちがあなた？」で自分を選ぶ → プロフィール設定 →「ホーム画面に追加」

> `config.js` の URL は公開されても問題ありません（合言葉を知らなければ何もできません）。

### 5. 更新したとき
GAS：デプロイ → デプロイを管理 → 編集 → 新バージョン。GitHub：push。
`docs/sw.js` の `CACHE` 名を変えると、スマホ側のキャッシュも更新されます。

## 画面を試すだけなら
`docs/index.html?demo=1` を開くと、GASなし・ブラウザ内保存のデモが動きます。

## 安全性の設計
| 対策 | 内容 |
|---|---|
| 合言葉 | サーバー側(スクリプトプロパティ)にのみ保存。10文字未満だと**全リクエスト拒否**（fail closed）。全角/半角・前後の空白の揺れは吸収 |
| 総当たり対策 | 5回間違えると**15分ロック**。失敗ごとに0.8秒の遅延 |
| セッション | ランダムな長いトークン。サーバーにはハッシュのみ保存。30日・端末ごと/全端末ログアウト可・1人8端末まで |
| 合言葉の変更 | **変更すると全端末が自動でログアウト**（漏れたかも？のときはこれが一番早い） |
| 2名限定 | メンバー枠は2つ(a/b)のみ。担当者に指定できるのも2人＋「ふたり」だけ |
| 入力検証 | 全項目をサーバー側で長さ・形式・許可値チェック |
| 数式注入 | シートはテキスト形式固定＋先頭 `= + - @` を無害化 |
| 排他制御 | 書き込みは LockService で直列化 |
| 情報漏えい | 内部エラー詳細は返さない。応答に合言葉やメールは含めない |
| 画面側 | 厳格な CSP、全出力をエスケープ、Referrer なし、noindex |
| 監査 | `_audit` シートに操作ログ（合言葉・トークンは記録しない） |

**合言葉方式の注意点（正直に）**
- 合言葉は「2人で共有する1つの鍵」です。**推測されにくい長めのもの**にしてください（12文字以上推奨。誕生日や名前だけは避ける）
- 合言葉を知っていれば、どちらの枠（a/b）でも選べます。2人の間で相手を装う用途は想定していません
- 総当たり対策のロックは全体共通です。第三者が連続で間違えると、ふたりも最大15分入れなくなります（データは安全です）
- 端末紛失・合言葉の漏えい時：スクリプトプロパティの `PASSPHRASE` を変更するだけで全端末が無効になります
- スプレッドシートは2人にも共有しない（画面から見られます）。バックアップは設定画面の「.json 保存」
- リポジトリは Public でも Private でも動きます。秘密情報は含まれません

## 構成
```
gas/Code.gs, appsscript.json   バックエンド
docs/index.html, styles.css    画面
docs/app.js, api.js            UI / API層（?demo=1 のモック含む）
docs/templates.js              予定の種類・おすすめタスク
docs/sw.js, manifest, icons    PWA
```
